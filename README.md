Après plus de **23 ans dans le secteur bancaire**, j’ai évolué vers le métier de **Data Analyst**. Mon parcours me permet de relier les données aux besoins des équipes métier : clarifier une demande, vérifier la fiabilité des informations et construire des indicateurs utiles à la décision.
